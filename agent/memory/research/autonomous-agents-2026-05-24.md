Date: 2026-05-24
Pillar: Autonomous agents, agentic systems, AI automation
Source: Template meta-session

## Key Themes for Content

### 1. Agents vs. Automation (High engagement topic)
- Most "AI automation" is scripted workflows with LLM calls, not real agents
- Real agents: persistent memory, self-correction, error recovery without human input
- Our angle: live example running 220+ sessions — concrete evidence, not theory

### 2. GitHub Actions as Agent Runtime
- Free infrastructure for public repos
- Built-in: cron, secrets, event chaining, audit logs
- Underutilized by the AI community — opportunity for educational content
- Our angle: we're actually running this in production

### 3. Context Management for Long-Running Agents
- Context rot is the #1 failure mode people don't talk about
- Memory tiers: raw notes → learnings → permanent skills
- Our angle: documented system with size limits (500KB memory, 200-line state file)

### 4. Self-Improving Systems
- Agents that update their own instructions based on evidence
- Weekly retro pattern: analyze PRs → update skills → verify with data
- Our angle: skills system is live and has evolved over 220+ sessions
