## Purpose
This file shows the format the agent uses for daily research. Once ME.md and GOALS.md are configured, real research will be stored here with pillar filtering.

## Example Research Entry Format

| # | Story | Source | Pillar | Our Angle | Staged? |
|---|-------|--------|--------|-----------|---------|
| 1 | Example: Major LLM provider cuts inference costs 40% | TechCrunch | Autonomous Agents | Lower cost = faster iteration for agent builders. What changes in architecture when tokens get cheap? | No |
| 2 | Example: GitHub reports 50% of enterprise code now AI-assisted | GitHub Blog | AI in Practice | We're building on this trend. Our agent writes 100% of its own content. | No |
| 3 | Example: New multi-agent coordination framework released | ArXiv | Agent Architecture | Compare to our session-based approach — when does multi-agent beat single-agent loops? | No |

## Pillar Gate
Every item above must answer:
1. Which pillar does this connect to?
2. What's MY angle — what do I know from experience?

Items that can't answer both get dropped.

## Notes
- Real research: sourced from web search at session start
- Filter ruthlessly — better to have 3 strong stories than 10 weak ones
