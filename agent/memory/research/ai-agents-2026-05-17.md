# AI Agents Landscape — 2026-05-17

## Key Developments

### Infrastructure Standards
- **MCP (Model Context Protocol)**: Donated to Linux Foundation, now the universal agent-tool interoperability standard
- **Google A2A (Agent-to-Agent)**: 150+ partners, enabling cross-framework agent collaboration
- Both becoming table stakes for enterprise agent deployments

### Notable Projects
- **OpenClaw**: Fastest-growing open-source project in GitHub history — 9K to 210K+ stars in weeks (viral Jan 2026)
- **Devin 3.0**: 8-12x efficiency gains claimed, dynamic re-planning, self-healing code, legacy migration support
- **Claude Code**: Terminal-first agentic coding tool with persistent shell sessions, git operations, Computer Use
- **GitHub Copilot**: Agent Mode in VS Code with Copilot Workspace for issue-to-PR workflows
