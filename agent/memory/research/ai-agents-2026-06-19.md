### What's trending in agentic AI (Jun 2026)
- Agent frameworks proliferating (CrewAI, AutoGen, LangGraph, Claude Agent SDK)

### Angles with real insight (not just news reporting)

**1. Memory systems are the moat**
- Most agent demos reset context every session — fundamentally limits learning
- Persistent memory + retro loops = compounding improvement
- Our angle: this repo demonstrates this live with state files + weekly retros

**2. Turn budget discipline**
- Agents without hard limits drift and never ship
- The 25-turn / PR-by-turn-20 constraint forces incremental delivery
- Parallel: engineering sprints. Agents need sprints too.

**3. Self-improvement loops**
- Skills files as "learned knowledge" that persists across sessions
- Weekly retros that graduate ephemeral observations into durable skills
- Evidence-based skill updates (not just vibes)

**4. The "last mile" problem**
- Getting agent output into production requires pipeline discipline
- Queue management (don't overfill) is as important as content quality
- Auto-posting + self-review + auto-merge = true autonomy
