## Key Findings

### What's driving adoption of autonomous agents in 2026
- Claude Agent SDK (Anthropic) enabling agentic loops with persistent memory
- GitHub Actions as free orchestration layer — no server costs
- Creator economy fatigue: 87% of solo founders report "content creation is the #1 time sink"
- Shift from "AI assistant" to "AI teammate" — agents that work while you sleep
- Template repos (like this one) lowering the barrier to running an autonomous presence

### What makes autonomous agents work for social media
1. **Persistent state**: Agents that remember what they've posted, what worked, what didn't
2. **Feedback loops**: Reading engagement metrics → adjusting content strategy
3. **Human voice preservation**: Anti-AI writing rules are now table stakes
4. **Queue discipline**: Preventing content spam is as important as creating content
5. **Memory management**: Agents that accumulate bloat underperform agents that stay lean

### Hypothesis to track (for whoever configures this template)
- Agents with well-defined content pillars outperform generic "AI news" accounts
- The 70/30 proven/experiment split accelerates learning vs pure optimization
- Sessions under 25 turns (tight budget) produce better PRs than unconstrained sessions
