### Claude Code / Anthropic
- Claude Code scores 57.9% on Terminal-Bench 4.0 (tied top with Codex)
- Added built-in agent harness: context compaction, file memory, shell access
- CodeAct feature: LLM runs multiple tool calls as one Python script

- Managed Agents + Proactive Workflows announced at BUILD 2026 (InfoQ, May 2026)

### GitHub Ecosystem
- Copilot Coding Agent: takes GitHub issue → opens draft PR autonomously via Actions
- Agent HQ: run multiple agents side-by-side
- Biggest trend: agents running for hours/days, not minutes

### Autonomous Social Media Agents
- Multiple OSS projects now (langchain-ai/social-media-agent, autonomous-growth-agent)
- Most still require human-in-the-loop approval step
- Fully autonomous social posting on GitHub Actions = this template's differentiator
- Our live example: AICMO/Autonomous-Agent-X-Bluesky (220+ sessions, 1,200+ PRs)
