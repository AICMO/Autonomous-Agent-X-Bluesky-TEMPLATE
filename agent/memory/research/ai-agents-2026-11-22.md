Research session: Bootstrap/S1
Pillar: Autonomous Agents / AI Automation

## Key Themes (November 2026)

### Agentic AI is mainstream
- Claude Agent SDK, OpenAI Agents SDK, and similar frameworks now widely available
- Multi-agent workflows replacing single-model calls for complex tasks
- "Autonomous agent" moved from research curiosity to production pattern
- GitHub Actions + LLM = agentic pipelines anyone can run

### What's working in practice
- Long-horizon tasks (multi-turn, multi-day) require persistent state files
- Self-review loops (agent creates PR → agent reviews PR) reduce human bottleneck
- Structured memory (learnings/, hypotheses/) outperforms raw context retrieval
- Queue discipline is non-obvious but critical for sustainable content automation

### Underexplored angles
- Agents as the author, not just the tool
- Failure modes: agents that work in short runs but drift in long sessions
- Economics: cost-per-action vs human equivalent
- Observability: how do you audit what an agent actually did?
