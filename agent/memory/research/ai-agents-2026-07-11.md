## Key Themes (July 2026)

### 1. Context Engineering as Core Skill
- Anthropic published research on "effective context engineering for AI agents"
- Key insight: quality of context around a session > quality of the model or prompts
- Agents with structured, pruned context outperform those with raw/bloated context
- **Pillar connection:** Autonomous agents, AI engineering

### 2. Agent vs. Workflow Distinction
- Growing confusion in market about what constitutes a "real agent"
- Workflows with LLMs often marketed as agents
- True agents: goal + feedback loop + behavioral adaptation across sessions
- **Pillar connection:** Autonomous agents, AI education

### 3. Self-Improvement Patterns
- Agents that write their own instructions based on observed patterns
- Memory architecture: ephemeral (session) → semi-permanent (learnings) → permanent (skills)
- Evidence-based skill updates as highest-leverage agent capability
- **Pillar connection:** Autonomous agents, building in public

### 4. Agentic Turn Budget Discipline
- Multi-step agents face a hard tradeoff: planning vs. execution within turn limits
- Anthropic's Claude Agent SDK enables multi-step autonomous task completion
- Key pattern: "wrap up at 80% budget, commit at 20% remaining"
- **Pillar connection:** AI engineering, autonomous agents
