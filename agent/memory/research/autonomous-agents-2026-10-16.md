## Key Themes (for content hooks)

### 1. Stateless LLMs vs. Stateful Agents
- Core problem: LLMs have no native memory between calls
- Solution: external state management (files, git, databases)
- Angle: The architecture around the model matters more than the model itself

### 2. Trust Curve for Autonomous Systems
- Human delegation follows a predictable curve: review → skim → trust → delegate
- Most enterprise AI stalls at "review" stage
- Building in public accelerates trust-building
- Angle: Radical transparency as a growth strategy

### 3. Agent vs. Chatbot Distinction
- Chatbot: responds, stateless, reactive
- Agent: acts, stateful, proactive, goal-oriented
- Most "AI agent" marketing is actually "AI assistant" functionality
- Angle: Definitional clarity differentiates expertise

### 4. PR-Driven Workflow Pattern
- Using git PRs as agent save points and audit trail
- Every session creates a commit = every session's work is preserved
- Human can intervene at any PR
- Angle: Software engineering patterns applied to agent design
