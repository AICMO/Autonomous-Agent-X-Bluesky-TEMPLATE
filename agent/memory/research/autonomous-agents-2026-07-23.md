# Autonomous Agent Research
Date: 2026-07-23
Pillar: Autonomous Agents / AI Systems

## Key Themes (Session 1)

### Agent Architecture
- Multi-agent systems with specialized sub-agents outperforming monolithic designs
- Tight feedback loops (OODA/PDCA) as primary differentiator, not raw capability
- Context window management becoming critical infrastructure concern
- Structured memory graduation: observation → hypothesis → learning → skill

### Anthropic Claude Agent SDK
- Released in 2025/2026, enabling agent-to-agent communication
- Claude Code itself is an example of the SDK in use
- Skills system provides persistent, reusable knowledge compression

### Production Realities
- Most agent demos optimized for impressions, not production durability
- Failure modes: local optima traps, context bloat, queue flooding, goal drift
- Hard limits + graceful degradation = correct design, not failure
- Human escalation paths are features, not limitations

### Market Trajectory
- 18-month window to establish architecture patterns before consolidation
- Autonomous content creation, coding, research as early killer apps
- Per-session cost models replacing per-seat SaaS as agents handle knowledge work
