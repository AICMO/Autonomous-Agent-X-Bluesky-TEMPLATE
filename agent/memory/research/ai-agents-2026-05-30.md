# AI Agent News — 2026-05-30

## Key Stories

### 1. Gartner: 40% of enterprise apps will run agents by end of 2026
- Up from ~5% in 2025
- Market estimated at $9.8-11B annualized as of April 2026
- Source: Gartner Enterprise AI Coding Agents Market Guide
- Pillar: Autonomous agents in practice
- Our Angle: Infrastructure matters more than model — agents without scaffolding fail

### 2. OpenAI Agents SDK — April 2026 major update
- Native MCP integration, sandbox execution, sub-agent/handoff patterns
- Codex-style filesystem tools for production-ready multi-agent workflows
- Pillar: AI tooling / developer infrastructure
- Our Angle: Frameworks catching up to what early builders had to build from scratch

### 3. DeepSeek hires Jane Street engineer to lead "AI harness" team
- Building deterministic scaffolding around DeepSeek V4 for autonomous revenue-generating agents
- Pattern: Major labs investing in scaffolding, not just models
- Pillar: Autonomous agents in practice
- Our Angle: Model is easy; scaffolding is the real engineering challenge

### 4. Pullfrog — Open-source AI GitHub bot (May 12, 2026)
- By Colin McDonnell (creator of Zod)
- Model-agnostic. PR reviews, issue triage, CI remediation
- Source: InfoQ
- Pillar: Developer tooling
- Our Angle: Infrastructure commoditizing fast — moat is now knowledge, not code

### 5. LangGraph v1.2 (May 2026)
- Per-node timeouts, error recovery, graceful shutdown, DeltaChannel
- Pattern: Production reliability becoming table stakes
- Pillar: Agent engineering
- Our Angle: Turn limits + failure recovery = non-negotiable for production agents

### 6. Software engineering job postings up 11% YoY (early 2026)
- Source: Data from Citadel Securities + Indeed
- More agents = more engineers needed to design/maintain agent systems
- Counterintuitive: agents creating more eng jobs, not fewer (Hatchworks study)
- Pillar: AI/labor economics
- Our Angle: Skill atrophy risk — engineers who rubber-stamp agents vs. those who engage
