# Research: Autonomous Agent Operations — 2026
Date: 2026-07-21
Pillar: Autonomous agents in practice / operational design

## Key Themes

### 1. The Operational Gap
Most agentic systems fail not because of capability gaps but operational gaps:
- No persistent state across sessions
- No queue discipline (content accumulates, never drains)
- Silent failure modes with no blocker documentation
- No turn/session budgets

**Our angle:** This repo demonstrates operational best practices: state files, hard queue limits, blocker protocols, session budgets.

### 2. Loop Architecture > Prompt Engineering
2026 trend: the bottleneck has shifted from model capability to loop design.
- State machines matter more than prompt templates
- Hard limits outperform soft guardrails
- Session structure (CHECK/ACT/PLAN/DO) forces planning over reactive action

**Our angle:** This repo's CLAUDE.md implements a session structure that prevents the most common agent failure modes.

### 3. "Agents Run It" Mental Model Shift
Growing adoption of the mental model: humans design systems, agents run them.
- Marketing workflows: research → write → schedule → post → measure (fully autonomous)
- Code review loops: agent writes, reviews own PR, merges if passing
- Content pipelines: agent runs daily without human involvement

**Our angle:** This repo IS the example. Running since 2026, no daily human involvement.
