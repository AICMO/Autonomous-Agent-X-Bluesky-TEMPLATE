## Key Stories

### 1. OpenAI launches "dots" — always-on agents
- Always-on agents that pursue goals across applications with limited supervision
- Powered by GPT-6 Astra
- Works through Slack and Teams
- Can manage projects, update sales proposals, research info, analyze data, build software (Codex + ChatGPT Work)
- Pillar: Autonomous agents in practice | Our Angle: Compare to agent architecture in this repo — dots shows where autonomous agents are heading

### 2. Manus raises $500M Series A
- Rebuilt platform with "Cascade" orchestration layer + "Cloud Computer" persistent execution environment
- Event-triggered automations
- $500M raise after China blocked Meta acquisition attempt
- Pillar: AI industry / autonomous agents | Our Angle: Persistent execution environments = core architecture decision for any autonomous agent builder

### 3. Microsoft Execution Containers for agent security
- Restricts agents from accessing unauthorized data or performing unapproved actions
- Support from OpenAI, Anthropic, Nvidia planned
- Published operational playbook: 3 paths (Agent Builder, Copilot Studio, Foundry)
- Pillar: Autonomous agents / enterprise AI | Our Angle: Security-first design matters; this repo uses GitHub Actions sandboxing for same reason

### 4. Google Gemini across Workspace
- Gmail, Calendar, Drive access
- Supports multiple AI models including Claude
- Coordinates multi-step tasks and sub-agents
- Pillar: Autonomous agents | Our Angle: Multi-model agents are becoming standard — single-model dependence is an architecture smell

### 5. AgentPlane launch — 35+ coding agents locally
- Supports Claude Code, Codex, 35+ agents running side-by-side
- Security features + Composio triggers
- Pillar: Developer tooling / autonomous agents | Our Angle: The local-agent-hub pattern mirrors what GitHub Actions provides for cloud-based agents

### 6. Harness acquires Augment Code assets
- Integrating AI coding agents into DevOps delivery platform
- Pillar: Developer tooling | Our Angle: AI coding agents becoming table stakes in DevOps pipelines
