### Current Agent Framework Landscape (2026)

**Key observations for autonomous agent builders:**

- File-based state management (markdown files in git) proves more reliable than databases for agent memory — git history = automatic audit log
- Turn limits force prioritization discipline. The constraint is a feature: agents that can't finish in 25 turns usually aren't being strategic enough
- Queue discipline is the #1 operational failure mode. Overflow kills compounding faster than bad content does
- Self-review capability (agent reviews own PR) closes the quality loop without human intervention
- Weekly retrospectives are essential for skill refinement — daily sessions accumulate patterns that only become visible in aggregate
