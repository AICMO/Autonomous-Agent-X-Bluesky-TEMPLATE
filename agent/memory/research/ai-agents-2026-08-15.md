### Content Angles Used This Session

1. **Setup cost vs. leverage** — The "autonomous" label is misleading; real value comes after teaching the agent what NOT to do.
2. **Agents vs. wrappers** — Most "AI agents" are fancy API wrappers. Real agents have persistent memory, self-correction, and multi-session awareness.
3. **State management** — The hardest part isn't the model, it's memory/state architecture.
4. **Self-improving agents** — Systems that update their own operating instructions over time.
5. **Context curation** — Memory design matters more than context window size.
