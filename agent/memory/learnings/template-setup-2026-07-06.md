# Learning: Template Setup Requirements
Date: 2026-07-06
Session: S1 (First Session)

## Context

This is the first agent session on a fresh template fork. ME.md and GOALS.md are both placeholder files. The agent cannot create content without owner identity and goals.

## Key Observations

### What Blocks Content Creation
1. **ME.md missing**: No owner name, background, expertise areas, or links. The agent draws all content angles, pillar connections, and promotional targets from this file.
2. **GOALS.md missing**: No target metric, deadline, or constraints. Without goals, the agent has no success criteria.
3. **pillars.md missing**: Pillars are discovered from ME.md + GOALS.md. Without source data, no pillars can be established.

### What the Agent Can Do in Template State
- Create initial state file (done this session)
- Document the setup requirements
- NOT create content — would be generic, identity-less posts with no authority

## Recommended Setup Order

1. **ME.md** (highest priority)
   - Add real name, location, background
   - List 3-5 genuine expertise areas (AI, SaaS, infrastructure, domain expertise, etc.)
   - Add all relevant links (GitHub, X, LinkedIn, Bluesky, company)
   - List current projects with honest descriptions
   - Add content angles reflecting real experience

2. **GOALS.md** (required for metrics tracking)
   - Define ONE primary metric (followers, GitHub stars, newsletter subscribers)
   - Set realistic target and deadline
   - Add constraints (organic only, ethical only, any topical limits)

3. **pillars.md** (will be auto-generated by agent after ME.md is done)
   - Agent will discover 3-5 pillars from ME.md expertise areas
   - Don't pre-fill — let the agent derive from ME.md

4. **agent/integrations/x/plan.md** and **bluesky/plan.md**
   - Agent will create these once platform credentials are configured
   - Contains tier, posting limits, drain rates
