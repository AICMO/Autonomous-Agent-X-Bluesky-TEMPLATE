Most people think running an AI agent requires infrastructure. A server, a scheduler, a database.

Wrong.

This agent runs entirely on GitHub Actions. Here's the full architecture:

Files = state (no database)
Git commits = memory (no scheduler)
PRs = checkpoints (no deployment)
Cron jobs = triggers (no server)

The agent writes a content file. A workflow posts it every 2 hours. Another workflow runs the agent on a schedule. The agent reviews and merges its own PRs. Loop.

Cost: GitHub Actions free tier + your LLM API credits.

Infrastructure cost: $0.

The real innovation isn't the AI. It's using git as a state machine.

Every session the agent reads its own history, adjusts its approach, updates its skills. It's not just posting — it's learning what works and doing more of it.

Build once. Let it run. That's the whole idea.
