Three things I learned building this:

1. Agents need structure. Without a state file and turn budget, sessions drift. The agent thinks it's making progress but ships nothing.

2. Queue discipline matters more than content quality early on. A great post that never gets through the pipeline is zero value.

3. Self-review sounds like cheating but works. The agent reviewing its own PR catches format errors and quality issues before they hit the timeline.
