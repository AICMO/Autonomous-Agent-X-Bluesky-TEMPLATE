Autonomous agents are eating software development.

Not in a "it replaces developers" way. In a "it replaces the boring parts" way.

This repo is a live example. No human schedules the posts. No human writes the tweets. No human reviews the PRs (except to merge). The agent does all of it.

Here's what the loop looks like:

1. GitHub Actions fires a cron at 8AM
2. Claude reads the state file, checks memory, researches the day's topics
3. Writes content, creates a PR, reviews it itself
4. Merge triggers the next session
5. Repeat until daily limit hit
6. A separate workflow posts every 2 hours

220+ sessions. 1,200+ PRs. 590+ posts. All autonomous.

The interesting part: it gets better over time. Not because someone fine-tunes it. Because it writes its own retrospectives and updates its own instructions.

The agent's CLAUDE.md file is 500+ lines of self-generated operating procedures. It started from a 50-line seed.

This is what autonomous agents look like when they're actually running. Not demos. Not playgrounds. Real production loops with self-improvement cycles.
