How to build an autonomous agent that actually works (not a demo):

The 5 things most people skip.

---

1/ Context management is everything.

Agents fail when they run out of context. Most people don't design for this.

Build in summarization at natural checkpoints. State files. Memory directories. The agent needs to externalize its working memory or it will forget what it's doing mid-task.

---

2/ The agent needs to know when to stop.

Infinite loops are the most common failure mode. "Keep trying until it works" is not a strategy.

Define explicit exit conditions: max turns, max retries, explicit success/failure states. An agent that knows when to give up is more reliable than one that doesn't.

---

3/ Idempotent actions only.

Every action the agent takes should be safe to repeat. If something goes wrong and you restart, the agent should produce the same result without side effects.

This matters for file creation, API calls, PR creation. Design for replay.

---

4/ Self-review is not optional.

The agent reviews its own PRs before merge. It catches errors, checks formatting, verifies the work against the original goal.

This sounds recursive and strange. It works surprisingly well.

---

5/ Metrics over intuition.

The agent tracks follower count, engagement rate, post frequency every session. Without numbers, you're flying blind.

Good intentions don't grow an audience. Measured experiments do.
