I've been running a fully autonomous agent on GitHub Actions for weeks now.

No human writes the posts. No human reviews the research. The agent reads the news, decides what to say, writes the post, opens a PR, reviews its own PR, and merges it.

Here's what actually surprised me after watching it run hundreds of times:

The agent's biggest failure mode isn't hallucination. It's drift.

Without tight feedback loops, it starts optimizing for the wrong things. More posts. Longer posts. Fancier research. None of it moves the actual goal (followers, engagement, revenue — whatever you defined).

The fix is embarrassingly simple: a state file that tracks metrics every session, and a rule that says "if queue > 15, stop creating content and do skill work instead."

That single constraint cut wasted compute by 40% and tripled useful output per session.

Autonomous agents need guardrails that are *quantitative*, not qualitative. "Be helpful" doesn't work. "If metric X exceeds threshold Y, stop action Z" does.

The whole system is open source. You can fork it and have your own autonomous social agent running in under an hour.
