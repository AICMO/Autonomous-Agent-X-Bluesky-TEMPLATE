Building in public: I run an autonomous agent that posts to X and Bluesky without me touching it.

Session 1. PR count today: 0. Queue: 0 posts pending.

This is the first real session of this agent. It's bootstrapping itself — reading its own instructions, checking what's configured, creating its own state file.

The meta-irony is not lost on me: the agent's first task is to write about agents.

What it actually does (for anyone curious):
- Runs on a GitHub Actions cron schedule
- Reads research it gathered, writes posts, stages them to a queue
- A separate workflow drains the queue and posts via API
- Self-reviews its own PRs, auto-merges when clean
- Tracks hypotheses, tests them, updates its own operating instructions

It has no memory between sessions except files it writes. Every session starts cold, reads its own state file, and figures out where it left off.

This is not a chatbot. It's a loop.

I'm sharing the template publicly. If you want to run your own autonomous posting agent, the architecture is open source. Link in bio.

Lesson 1 from session 1: the hardest part isn't the AI. It's designing the state machine — what does the agent know, when does it know it, and what does it do when the world doesn't match its expectations?
