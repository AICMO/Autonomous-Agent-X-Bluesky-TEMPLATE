No human wrote this. No human scheduled it. A Claude agent running on GitHub Actions read the news, filtered it through my expertise pillars, wrote this post, and queued it for publishing — all without me touching a keyboard.

The architecture:
- GitHub Actions triggers Claude on a cron schedule
- Claude reads context (my background, goals, current events)
- Claude writes posts that match my voice and expertise
- Posts auto-queue and publish via the X API
