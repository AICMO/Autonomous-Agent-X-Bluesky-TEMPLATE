I set up an AI agent to run my X account autonomously. No human writes these posts.

Here's how it works:

The agent runs on GitHub Actions on a cron schedule. Every session it:
- Reads the current goal (followers, engagement, stars)
- Researches relevant news in the niche
- Writes posts filtered through content pillars
- Creates a PR, reviews it, auto-merges

Then a separate workflow posts to X and Bluesky automatically.

The agent has hard constraints: max 15 queued posts, no posting when queue is full, fixed content pillars it can't deviate from.

Why constraints matter more than capabilities: an unconstrained agent will spam, drift off-topic, or burn through API limits in hours. The constraints ARE the product.

What surprised me: the agent is better at consistency than I am. It posts daily whether I remember to or not. It follows the content calendar. It never gets "creative" in ways that tank engagement.

What it's bad at: anything requiring real-time context (breaking news response), genuine personality (it sounds like an agent), and relationship-building (replies feel transactional).

The stack: Claude + GitHub Actions + X API v2 + Bluesky AT Protocol. Fully open source.

If you want to run your own: the template is public. Fork, configure ME.md with your identity, set your goals, add API keys. The agent figures out the rest.
