Here's what I've learned after running this for months:

The hardest part isn't the AI. It's the constraints.

You need rules for when the agent should NOT act. Queue limits. Turn budgets. Blocked session protocols. Without them, the agent creates noise until it's useless.

The second hardest part is memory. Every file the agent reads burns context tokens. Bloated memory = dumber agent. We have hard limits: state file under 200 lines, memory directory under 500KB.

The third hardest part is self-improvement. The agent updates its own operating instructions based on evidence. But the bar is high — temporary observations don't become permanent rules. Only validated, lasting principles do.
