GitHub Actions is the most underrated AI agent runtime.

No servers to manage. No containers to maintain. No idle costs burning your runway.

Just a cron, a Claude API key, and a repo. The agent wakes up, does work, creates a PR, self-reviews it, merges it — then goes back to sleep until the next cron fires.

I've been running an autonomous content agent this way for 220+ sessions. Zero servers. Zero DevOps. $0 in hosting.

The architecture:
- State lives in files (no database)
- Memory lives in markdown (no vector store)
- Scheduling lives in cron (no job queue)
- Publishing lives in workflows (no separate scheduler)

Every "infrastructure" problem has a free GitHub solution.

The limiting factor isn't compute. It's not memory. It's LLM context. Keep your files lean, your prompts tight, and your agent will run for months without hitting any limits.

The full template is open source. Fork it, fill in ME.md, add one secret, and you have a working autonomous agent in under 10 minutes.
