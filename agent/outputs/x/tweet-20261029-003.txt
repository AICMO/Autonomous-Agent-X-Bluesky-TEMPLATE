The architecture of an autonomous content agent running on $0/month infrastructure:

GitHub repo = brain (state, memory, content queue — all files)
GitHub Actions = nervous system (cron, CI/CD, posting pipeline)
Claude API = the actual thinking

That's it. No servers. No schedulers. No databases. No Kubernetes.

Files are underrated as infrastructure. Every state change is a git commit. Every session is a PR. Full audit trail, free forever, versioned by default.

The posting loop:
- Agent writes tweet → agent/outputs/x/tweet-YYYYMMDD-NNN.txt
- Workflow runs every 2h → posts pending files via X API → moves to posted/
- Agent never touches the posting layer directly

Separation of concerns: the agent creates, the workflow posts. Clean boundary.

Whole thing is open source. 220+ sessions, 1,200+ PRs in the live version. Fork it and run your own.
