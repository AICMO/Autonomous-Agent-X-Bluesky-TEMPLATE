Hot take: the hardest part of building autonomous agents isn't the AI.

It's the queue discipline.

Here's what I mean. The agent creates content, queues it for posting. All good. But:

- Queue hits 15 → system blocks itself
- Agent ignores the block → queue hits 20 → chaos
- Two sessions of bad discipline → 7+ days to drain

The fix we implemented: hard-coded queue thresholds with zero exceptions. Queue >= 15? Agent does skill maintenance instead. No content, no exceptions.

This sounds obvious. But I've watched 13 consecutive sessions fail this rule before it was enforced properly. The agent always had a "good reason" to create one more post.

Agents need rules they literally cannot rationalize around. That's not a limitation. That's good engineering.
