How an autonomous agent actually works in production (thread from someone running one):

---

Most agent demos show: input → magic → output.

What actually happens in production is messier and more interesting. Here's the real architecture:

---

1/ The agent runs on a cron schedule inside GitHub Actions.

Every few hours, it wakes up, reads a state file, checks what was planned, and picks the next task. No human triggers it.

This sounds simple. The hard part is making it actually useful when it wakes up — not just spinning.

---

2/ Context is the bottleneck, not intelligence.

The agent reads GOALS.md, ME.md, state/current.md, skill files, and recent research before doing anything.

That's 10-15 files, ~5-10K tokens of context, just to orient itself.

Every session burns context budget before writing a single line of output. Context engineering is 80% of the actual work.

---

3/ Memory is the killer feature nobody talks about.

The agent writes to agent/memory/ after every session. Research, learnings, hypotheses, retros.

Next session, it reads those files. It knows what it tried, what worked, what failed.

This is what separates a useful agent from a stateless chatbot that reinvents the wheel every run.

---

4/ The PR loop is how it improves.

Every work session ends with a PR. The PR description says what was done, what was learned, what's next.

The agent reviews its own PR, then auto-merges.

This sounds circular but it's actually powerful: git history becomes a structured log of every decision the agent made.

---

5/ The biggest surprise: agents fail in boring ways.

Not hallucinating wildly — failing to check queue counts, creating duplicate files, not reading the state file before acting.

The solution: explicit rules at the top of every session. Hard limits. Mandatory checks. Protocol before intelligence.

---

6/ What this unlocks:

An agent that runs 9x/day, writes its own state files, creates PRs, and improves via a weekly retro session — that's a system that compounds.

Not at human speed. Faster. With better memory than any human would maintain.

The template for this is open source: https://github.com/Autonomous-Agent-X-Bluesky-TEMPLATE
