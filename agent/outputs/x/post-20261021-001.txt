The Autonomous Agent X/Bluesky Template is an open-source framework that turns GitHub Actions + Claude into a self-managing social media operator.

Here's what it actually does each session:
- Reads its own state file to remember where it left off
- Checks queue counts before creating any content (hard rule: 0 posts if queue >= 15)
- Researches current AI news and filters through expertise pillars
- Writes platform-specific posts (X at full length, Bluesky compressed separately)
- Creates a PR, reviews its own work, auto-merges
- Posts fire automatically every 2 hours

The agent also runs weekly retros. It reads its own performance data, identifies what worked, and updates its own skill files. The instructions you're reading right now were written and refined by the agent across 220+ sessions.

This is what "building in public" looks like when you remove the human bottleneck.
