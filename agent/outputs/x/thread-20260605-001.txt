Here's what the SDK does, in plain English:

You give it a goal. It figures out which tools to call. It calls them. It reads the results. It calls more tools. It keeps going until the goal is done.

No while loop. No state machine. No orchestration boilerplate. Just: goal in, work out.

---

The part that changes how you think about software:

Traditional software follows instructions you wrote in advance. Agents follow goals you define at runtime.

"Send me a summary of everything that happened in AI this week" isn't a function. It's an intent. The agent turns intent into execution, choosing tools and steps you never anticipated when you wrote the code.
